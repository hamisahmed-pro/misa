# MisaApp — iOS template project (M7)

Open `MisaApp.xcodeproj` in Xcode on a Mac. The project compiles the
Misa runtime from `../impl/misa/aot/rt/` and links your program.

## First build

1. Build your program object on Linux:
   `misa build --target aarch64-apple-darwin -o prog_arm64.o app.misa`
2. Copy `prog_arm64.o` into `program/` (next to this README).
   Xcode links it automatically — no project changes needed.
3. Open the project, set your Development Team (Signing & Capabilities),
   pick your iPhone as the run destination, and press Run.

## What's inside

- `MisaApp.xcodeproj` — generated by `gen_xcodeproj.py` (re-run it if
  you change the file list; the generator checks that every referenced
  object id is defined).
- `Info.plist` — no storyboard (UI is 100% programmatic via the UIKit
  driver); includes `NSCameraUsageDescription` for `CameraButton`.
- `program/` — drop `prog_arm64.o` here. For the simulator, build
  `prog_x64.o` (`--target x86_64-apple-darwin`) and swap the file.

## Signing

Free Apple ID = direct device install, signature lasts ~7 days.
Paid Developer Program (~$99/year) = TestFlight + App Store.
Full checklist: `docs/ios-cross.md` §8.

# Task T01 — FizzBuzz (Tier 1: core language)

## Goal
Write a Misa program that prints FizzBuzz from 1 to 30.

## Requirements
- Use a `for` loop and `if`/`else` conditionals.
- For multiples of 3 print "Fizz", multiples of 5 print "Buzz",
  multiples of both print "FizzBuzz", otherwise the number.

## Acceptance
- `misa check program.misa` is clean.
- `misa run program.misa` prints exactly 30 lines; line 3 is "Fizz",
  line 5 is "Buzz", line 15 is "FizzBuzz", line 1 is "1", line 30 is
  "FizzBuzz".

## Rules
- Max 15 check/fix iterations. Read the spec files first.
- Use `misa check --json` for machine-readable errors.

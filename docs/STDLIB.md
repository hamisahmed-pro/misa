# Misa Standard Library (`std`)

Bundled with the toolchain. Import a module by path:

```misa
import "std/strings"
```

`import "std"` loads every module. Imports share one flat
namespace with your program (a duplicate name is E110).

> Generated by `python3 stdlib/gen_docs.py` — do not edit by hand.

## `std/strings`

### `fn is_space(ch: Text) -> Bool`

True for the four ASCII whitespace characters: space, tab,
newline, carriage return.

### `fn starts_at(s: Text, i: Int, sub: Text) -> Bool`

True if `sub` occurs in `s` starting exactly at index `i`.

### `fn trim(s: Text) -> Text`

Returns `s` with leading and trailing whitespace removed.
Interior whitespace is kept exactly as-is.

### `fn split(s: Text, sep: Text) -> [Text]`

Splits `s` on every occurrence of `sep`. An empty `sep` returns `[s]`.

### `fn join(parts: [Text], sep: Text) -> Text`

Joins `parts` with `sep` between them. `[]` gives `""`.

### `fn starts_with(s: Text, prefix: Text) -> Bool`

True if `s` starts with `prefix`.

### `fn ends_with(s: Text, suffix: Text) -> Bool`

True if `s` ends with `suffix`.

### `fn contains(s: Text, sub: Text) -> Bool`

True if `sub` occurs anywhere in `s`. An empty `sub` is always found.

### `fn repeat(s: Text, n: Int) -> Text`

Returns `s` repeated `n` times. `n <= 0` gives `""`.

### `fn pad_left(s: Text, width: Int, pad: Text) -> Text`

Returns `s` left-padded with `pad` to `width` characters.
`pad` should be one character; longer pads may overshoot the width.
A `s` already `width` or wider is returned as-is.

### `fn pad_right(s: Text, width: Int, pad: Text) -> Text`

Returns `s` right-padded with `pad` to `width` characters.
See `pad_left` for the padding rules.

## `std/lists`

### `fn range(n: Int) -> [Int]`

Returns `[0, 1, ..., n-1]`. Empty for `n <= 0`.

### `fn any(xs: [Bool]) -> Bool`

True if any element is true. False for `[]`.

### `fn all(xs: [Bool]) -> Bool`

True if every element is true. Vacuously true for `[]`.

### `fn sum(xs: [Int]) -> Int`

The sum of the elements. `0` for `[]`.

## `std/json`

### `fn escape(s: Text) -> Text`

Returns `s` with JSON string escaping applied: double quotes,
backslashes, newlines, tabs, and carriage returns are escaped.
Use it to safely embed text inside a JSON string value.

### `fn quoted(s: Text) -> Text`

Returns `s` as a JSON string literal, surrounding quotes included.

## `std/http`

### `fn get_text(url: Text) -> Text`

GETs `url` and returns the response body as text.
On failure throws an Error naming the URL and the cause, e.g.
`GET https://example.com/x: E304: http.get failed: ...`.

## `std/result`

### `fn throw_err(code: Text, message: Text)`

Builds and throws an Error in one step.
The caught value is an Error with `.code` and `.message`.
